# Third-Party Software Notices

This project uses third-party software and tooling. The license information below is
intended as a starting point for a complete compliance checklist before public
launch. Each dependency should be reviewed against its own terms and the exact
version used by the project.

## Core engine and tooling
- GLFW — zlib/libpng license
- GLM — MIT license
- Vulkan Headers — Apache 2.0 or license terms designated by the project
- glslang — Apache 2.0
- Dear ImGui — MIT license
- nlohmann/json — MIT license
- miniaudio — MIT license or project-specific license terms
- Volk — MIT or license terms designated by the package

## Notes
This list should be maintained as the dependency set changes. Do not assume a
component is safe to redistribute or reuse without keeping the original copyright,
license text, and attribution notices.

## Internal policy
Before public launch, the project should keep a current dependency inventory and
store the full license text for any package that is redistributed or shipped with
the game.
